# Checklist de mise en ligne gratuite (0 €)

Cochez chaque étape. Aucun achat requis sauf mention « optionnelle ».

## 1. Compte de paiement (socle obligatoire)
- [ ] Compte **Payoneer** ouvert (pièce d'identité malgache) — https://www.payoneer.com
- [ ] **Compte de réception EUR** activé dans Payoneer
- [ ] Fonction **Payment Request** testée (voir étape 6)
- [ ] Coordonnées bancaires **MCB** ajoutées pour le retrait (SWIFT MCBLMGMGXXX)

## 2. Hébergement gratuit (sous-domaine)
- [ ] Compte **Netlify** (netlify.com) OU **GitHub Pages** créé
- [ ] `index.html` (page de vente) déployé → vous obtenez `votresite.netlify.app`
- [ ] (Optionnel, ~10 €/an) nom de domaine `.fr`/`.com` acheté et relié — NON requis pour démarrer à 0 €

## 3. Page de vente
- [ ] Texte promesse + offre + prix (HT, B2B) en place
- [ ] Formulaire de contact connecté (Formspree gratuit : remplacer `VOTRE_ID_FORMSPREE` dans `index.html`)
- [ ] FAQ, CGV, mentions légales, politique RGPD présents (sections déjà dans `index.html`)
- [ ] Bouton CTA « Devis gratuit » fonctionnel (ancre `#devis`)

## 4. Preuve (sans faux témoignage)
- [ ] 2 sites démo réels créés à partir de `site-client-template.html` (ex. coiffure-lyon, plomberie-bordeaux)
- [ ] Liens des démos ajoutés dans la section « Exemples » de `index.html`
- [ ] Emplacement réservé pour VRAIS témoignages (après 1re vente, avec accord)

## 5. Documents opérationnels
- [ ] Template de **devis** (Google Docs) prêt
- [ ] Template de **facture HT** avec mention reverse charge prêt
- [ ] Guide Google Business Profile prêt à envoyer

## 6. TEST DE PAIEMENT RÉEL (OBLIGATOIRE avant prospection)
- [ ] Envoyer une **Payment Request Payoneer** à un proche français pour 2–5 €
- [ ] Le proche paie par virement SEPA (ou carte)
- [ ] Vous lancez le **retrait vers MCB** et confirmez l'arrivée sur la carte
- [ ] Vous notez les frais réels dans `journal.md` (ex. ~3 % du montant)
- [ ] ✅ Si l'argent arrive sur MCB → vous pouvez prospecter. Sinon, résolvez le problème avant tout.

## 7. Acquisition (0 €)
- [ ] Liste de 200 cibles FR créée (Google Maps + groupes FB/LinkedIn)
- [ ] 10 contacts/jour programmés (DM/email/formulaire)
- [ ] 1 post de valeur/jour dans 2 groupes
- [ ] Suivi quotidien tenu dans `suivi-quotidien.md`

## Points de conformité
- [ ] Facturation **HT B2B** avec n° de TVA client + mention reverse charge (art. 196 directive 2006/112/CE)
- [ ] Mentions légales + CGV + RGPD visibles sur le site
- [ ] Pour toute vente B2C : case de renonciation au droit de rétractation (L. 221-28)
- [ ] Revenus déclarés en Madagascar (à confirmer avec un comptable local)
